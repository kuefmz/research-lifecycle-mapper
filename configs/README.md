# Configuration inventory

Only `heuristics/` is the final scientific profile. The installed
default is identical. Completed runs retain their original manifests; normalized release metadata changes catalog hashes.

Other configuration files are compatibility/data-ingestion tools:

- final-agreement-import.yaml: observed final_agreement workbook mapping.
- agreement-final-import.yaml: older Agreement Final mapping template; do not infer it
  describes the current workbook without checking headers.
- benchmark.yaml: historical formal research manifest workflow, not the recommended
  observed CSV assessment command.
- synthetic.yaml: offline software-verification fixture, explicitly pinned to baseline
  rules; not research performance.
- default.yaml: earlier method/protocol configuration metadata.

The maintained paper commands are in README.md and docs/data-generation.md. Actual run
parameters and manifests take precedence over older templates. Test-only historical
profiles are under tests/fixtures/legacy-profiles and are not alternative paper methods.
