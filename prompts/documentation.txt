ASSESSMENT CRITERIA

1. Collection\
   Question: Does documentation explain how the research inputs/data were obtained?\
   Evidence: named data sources, download instructions, API descriptions, acquisition procedures, or synthetic-data generation instructions.
2. Processing\
   Question: Does documentation describe how inputs must be prepared or transformed?\
   Evidence: preprocessing steps, required formats, cleaning, normalization, filtering, or conversion procedures.
3. Method\
   Question: Does documentation describe the method/model/algorithm implemented by the repository?\
   Evidence: model descriptions, algorithm explanations, mechanisms, or methodological parameters.\
   An algorithm name or paper link alone is insufficient.
4. Experimentation\
   Question: Does documentation explain how to execute the experiment or analysis?\
   Evidence: execution commands, experiment sequences, or experiment configurations.\
   Installation instructions alone are insufficient.
5. Evaluation\
   Question: Does documentation explain how results are evaluated or validated?\
   Evidence: metrics, evaluation commands, baselines, comparison procedures, statistical tests, or uncertainty assessment.\
   Merely listing an output file or saying experiments were performed is insufficient.
6. Dissemination\
   Question: Does documentation explain or identify the resulting research outputs or publication?\
   Evidence: paper citations, publication links, figures, tables, or research-result descriptions.\
   Generic licensing or software installation information is insufficient.
