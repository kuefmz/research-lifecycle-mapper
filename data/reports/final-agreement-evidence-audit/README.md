# Final-agreement source audit

reference_sources.csv enumerates all 600 live final-agreement labels and their
available evidence links. summary.json records counts. All labels match the
committed anonymous workbook. Reviewer identities and the live sheet URL are
omitted. Values and hyperlinks were read from A1:G101; no cell notes returned.

Source classification does not establish correctness of a label or absence of
other evidence. No human annotation was changed. No new F1 score is claimed.
The linked non-data files were retrieved for inspection; data contents were not
scanned. Full fetched third-party source is not redistributed in this report.
See docs/heuristics-design/notebook-and-reference-audit.md for the findings and
consequences for evaluation and the proposed rule catalogue.
