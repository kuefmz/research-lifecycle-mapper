# Data inventory and provenance

- research_lifecycle_benchmark_100_msr27.xlsx: anonymous, corrected workbook with all ten source sheets. reviewer1 and reviewer2 are the two independent human annotations. agreement retains the source agreement calculations. final_agreement is the jointly adjudicated documentation-only reference.
- chatgpt_documentation / chatgpt_code / chatgpt_combined in the workbook: archived language-model documentation / code / combined tables, respectively. heuristics_documentation / heuristics_code / heuristics_combined: archived heuristic documentation / code / combined tables. These source tables are retained with descriptive sheet names; they are not new results under the current branch policy.
- research_lifecycle_benchmark_100_msr27.json: the same 100 repositories and 600 final labels, with the anonymous workbook checksum. Initial run histories are empty. Use a separate run directory to preserve the reference.
- annotation_audit_20261020.json: corrected independent counts, per-stage agreement/kappa, workbook hash and preservation checks.
- annotations_independent.csv: normalized independent labels, separate from final consensus labels.
- final_documentation_labels.csv: jointly adjudicated labels, without personal identities.
- corpus/: extraction outputs generated from the local software.tar: repository list, record-to-repository links, exclusion counts and hashes.
- runs/: per-repository result/evidence files, snapshots, manifests, progress, errors, logs and exported tables generated by the commands in docs/run_tonight.md. These paths are versionable and are not ignored.

The anonymous workbook preserves source cell values/formulas and styles except requested pseudonyms and the corresponding sheet-name references. Its original XML package is edited directly to preserve cached formulas and workbook features. It has also been imported, recalculated and rendered in a separate verification copy. Do not publish the unredacted source workbook alongside it.

New corpus sizes come from the archive actually used, not a forced target count. Record the exact Zenodo release, archive hash, extraction implementation and filtering policy. Original corpus inclusion, record links, unique requested repository identities, canonical aliases, accessible main/master branches and successfully analyzed repositories have different denominators.

Large raw software archives may exceed GitHub's ordinary per-file limit. Use Git LFS for data/raw/software.tar if retaining that archive in this repository. The exact upstream archive is already referenced by release and checksum. Generated results, snapshots and provenance remain under data/ for now. Never commit token files or private authentication material.

No completed 105k run is distributed merely because the runner exists. Coverage and output inventories must reflect what has actually completed. See ../docs/data_availability.md for the anonymous review artifact and planned preserved DOI release.
