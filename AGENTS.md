# Repository workflow

The maintainer requests one maintained branch: `main`.

- Work directly on `main`; do not create implementation or feature branches unless the maintainer explicitly changes this preference.
- Inspect the current remote state and validate changes before publishing them to `main`.
- Keep automatic deletion of merged branches enabled. If an authorized pull request is used, merge it and remove its merged source branch.
- Never discard unmerged work merely to reduce the branch count; reconcile it with the maintainer first.

The research integrity requirements in the methodology and evaluation protocol continue to apply. Missing human annotations, approvals, snapshots or codebook decisions must remain explicitly pending.
