# LLM result provenance

The three original output tables are exported separately under
../benchmark-100/workbook/llm_documentation.csv, llm_code.csv and llm_combined.csv.
Exact user prompts, shared links and transcription checks are under ../../prompts/.

This folder is reserved for any additional original inference configuration, captured
inputs, retrieval records or raw outputs supplied later. Missing temperature, historical
model snapshot and tool/input details must not be inferred from the user prompts.
