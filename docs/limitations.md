# Current limitations

The 42-rule candidate catalog detects inspectable evidence rather than executed research activities, scientific validity or reproducibility. Documentation is mostly English. Explicit operation/context and activity/object rules miss indirect disciplinary descriptions, while documentation can overclaim and dead code can qualify. Measured agreement and its denominators are in the [implementation report](implementation_report_20261015.md); they do not establish external validity or optimal accuracy.

Python uses AST/tokenization; R, Julia, MATLAB and shell use conservative lexical masking. Complex quoting, nested/block comments, shell heredocs and MATLAB transpose syntax can limit lexical accuracy. Other inventoried languages have no positive code rules. Notebooks, binary documentation, symlinks/submodules, configuration formats and generated/vendored artifacts have limited or no detector coverage. The size ceiling, excluded paths, unavailable files and Python parse errors affect mode completeness. Unit-test paths are vetoed even when a project stores real scientific experiments there.

The final workbook has 600 complete consensus labels, but one independent annotation is missing. There are 246 disagreements among 599 valid independent pairs; the missing pair must not be fabricated as either agreement or disagreement. Consensus approval for observed comparisons comes from the explicit user brief. Separately approved human codebook and original sampling provenance remain unavailable. Annotation-time repository SHAs are unknown; current pinned commits may differ from what annotators saw.

The fixed operational test split was created before rule changes, but the full final-label table was available in the conversation. It is not independently blinded. Complete-case cohorts differ by mode and may be selected systematically by file size, language or acquisition failures. Full-benchmark and partial-scan metrics are exploratory. Two of 100 acquisitions failed and several recovered snapshots are partial; detailed inventories, evidence and failures are preserved privately.

Backend, rule, persistence, import, HTTP and DOM tests pass. Explicit Playwright execution remains blocked by a Chromium download failure; browser rendering and mobile layout were not verified. Docker image digests, remote CI and anonymous publication release were not verified. The older formal publication workflow still requires protocol/provenance adjudication and its guards must not be bypassed by inventing complete independent annotations. The upstream source was not copied or modified.
